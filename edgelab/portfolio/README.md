# edgelab.portfolio

**Rôle.** Combinaison de stratégies, corrélation, allocation sous contrainte de drawdown.

**Ce module refuse de faire.** Allouer sur le Sharpe ou le rendement espéré plutôt que sur la contribution au P(passage) du portefeuille.

**Statut.** Squelette — implémentation à venir selon l'ordre de phase défini dans `CLAUDE.md`.
