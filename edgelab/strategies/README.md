# edgelab.strategies

**Rôle.** Une stratégie = un dossier (spec Pydantic + fiche d'hypothèse + code).

**Ce module refuse de faire.** Démarrer un backtest sans fiche d'hypothèse validée contenant des critères de mort (I2).

**Statut.** Squelette — implémentation à venir selon l'ordre de phase défini dans `CLAUDE.md`.
