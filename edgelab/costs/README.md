# edgelab.costs

**Rôle.** Modèle de coûts explicite par instrument et par type d'ordre (spread, commission, slippage).

**Ce module refuse de faire.** Appliquer le même slippage à un ordre stop intra-barre et à une clôture de barre.

**Statut.** Squelette — implémentation à venir selon l'ordre de phase défini dans `CLAUDE.md`.
