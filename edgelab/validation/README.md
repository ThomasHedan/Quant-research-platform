# edgelab.validation

**Ce module refuse de faire.** Alimenter le DSR avec un nombre d'essais saisi à la main, ressusciter une stratégie marquée dead.

**Statut.** Squelette — implémentation à venir selon l'ordre de phase défini dans `CLAUDE.md`.
