# edgelab.data

**Rôle.** Ingestion, contrôle d'intégrité, store des données de marché et lockbox du holdout (I3).

**Ce module refuse de faire.** Raccorder des futures sans méthode explicite, laisser un dataset en quarantaine atteindre le backtester, exposer le holdout sans raison écrite tracée.

**Statut.** Squelette — implémentation à venir selon l'ordre de phase défini dans `CLAUDE.md`.
